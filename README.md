# Projeto de Capacitação – Equipe de Computação | IME Júnior

## 📌 Visão Geral
Este projeto consiste em uma **capacitação prática** desenvolvida para a **equipe de Computação da IME Júnior**, empresa júnior vinculada ao Instituto Militar de Engenharia (IME).

O objetivo principal foi consolidar conhecimentos fundamentais de **desenvolvimento web front-end**, colocando em prática conceitos de **HTML, CSS e JavaScript** por meio da criação de um sistema com múltiplas páginas e funcionalidades reais.

---

## 🎯 Objetivos do Projeto
- Capacitar os membros da equipe em desenvolvimento web;
- Aplicar conceitos de **HTML semântico**, **CSS** e **JavaScript**;
- Desenvolver páginas integradas e funcionais;
- Estimular boas práticas de organização de código e lógica de programação.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** – Estrutura das páginas  
- **CSS3** – Estilização, layout e organização visual  
- **JavaScript (JS)** – Interatividade, validações e lógica de funcionamento  

---

## 📄 Páginas e Funcionalidades Desenvolvidas

### 🏠 Home
- Página inicial do sistema;
- Navegação clara e organizada;
- Estrutura visual consistente.

### 🔐 Login
- Tela de autenticação de usuários;
- Coleta de informações;
- Validação básica utilizando JavaScript.

### 📝 Cadastro
- Formulário para cadastro de usuários;
- Tratamento e validação de dados;
- Integração com a lógica de login.

### 🛒 Loja
- Simulação de uma loja virtual;
- Implementação de **barra de pesquisa funcional**;
- Organização visual dos itens exibidos.

### 🧰 Serviços
- Página dedicada à apresentação de serviços;
- Layout padronizado com o restante do sistema.
